Sample Lighthouse Server Mesh Configs (3-server configuration)

Master <-- Slave 0 <-- Slave 1

Master (addr 0.0.0.0:8080)
{
	"role": "master",
	"self_addr": "0.0.0.0:8080",
	"slaves": ["0.0.0.1:8080", "0.0.0.2:8080"]
}

Slave 0 (addr 0.0.0.1:8080)
{
	"role": "slave",
	"self_addr": "0.0.0.1:8080",
	"parent_addr": "0.0.0.0:8080",
	"slaves": []
}

Slave 1 (addr 0.0.0.2:8080)
{
	"role": "slave",
	"self_addr": "0.0.0.2:8080",
	"parent_addr": "0.0.0.1:8080",
	"slaves": []
}

Reverse Proxy Example (nginx redirects port 5000 -> 5001)

Master behind nginx:
{
	"role": "master",
	"self_addr": "hostname:5000",
	"host_port": 5001,
	"slaves": ["slave1:5000", "slave2:5000"],
	"name": "Main Node"
}

- self_addr: Address other nodes use to reach this node (through nginx on port 5000)
- host_port: Actual port Flask binds to (5001)
- If host_port is omitted, Flask binds to the port from self_addr
